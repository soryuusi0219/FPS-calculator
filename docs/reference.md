# FPS calculator 機能リファレンス

ブラウザ内で、競技プログラミング・数え上げ向けの形式冪級数を厳密に計算するための利用マニュアルです。利用可能な構文、組み込み関数と別名、型・定義域、循環定義、画面操作、保存・共有、制限をまとめています。

ヘッダーの「ドキュメント」からこの文書を開けます。閉じるボタンまたはEscapeで計算ノートへ戻り、「Markdown保存」で本文を保存できます。文書を開いても式・履歴・計算設定は変わりません。

## はじめに

1. 1行に1つの式、または`名前 = 式`を入力します。
2. 行番号・入力欄・行の計算プレビューを選ぶと、その行の結果を表示します。
3. 「係数体」で有理数か素数mod、「打ち切り次数N」で精度を指定します。
4. 「係数表 / 級数」「O.G.F. / E.G.F.」で結果の表示を切り替えられます。

以下のコード例では、各ブロックを独立したノートとして使えます。指定がなければ有理数・O.G.F.・N=8程度を想定します。コードに説明用の行内コメントは入れていません。

```fps
F=1/(1-X)
G=exp(X)
F+G
G[3]
```

`F`の通常係数は`1,1,1,…`、`G`は`1,1,1/2,1/6,…`、最後の行はスカラー`1/6`です。式は入力後に自動で計算します。実行ボタンは不要です。

## 構文

### 数値と名前

- 数値リテラルは10進の非負整数です。負数は`-3`、有理数は`1/2`のように式で入力します。小数・指数表記・文字列・JavaScriptコードは扱いません。
- `x`と`X`は同じ形式変数です。名前はASCII英字または`_`で始まり、以後は英字・数字・`_`を使えます。名前の大文字・小文字は区別します。
- `F=式`は名前の定義です。別の行から参照でき、前方参照も可能です。同じ名前の重複定義はエラーです。
- `x`、`X`、`a`、`n`、`true`、`false`と組み込み関数名はグローバルな定義名にできません。`Catalan`も予約語です。
- `C`・`P`・`H`は通常の名前として使えます。組合せには`nCk`・`nPk`・`nHk`を使います。
- 名前付きラムダは呼び出せます。組み込み関数名そのものをラムダの代わりに渡すことはできません。
- `#`や`//`による行内コメント構文はありません。説明は各行の「コメント」へ入力します。

```fps
F=G+X
G=1/(1-X)
C=n=>nCk(2*n,n)
fps(C)
C(4)
make=m=>n=>m+n
make(2)(3)
```

### 演算子と優先順位

強いものから順に並べます。比較と論理演算の結果は真偽値です。

| 構文 | 意味・結合規則 |
| --- | --- |
| `(...)`、`f(...)`、`f[k]`、後置`!` | 括弧・呼び出し・係数抽出・階乗 |
| `^` | べき乗。右結合 |
| 単項`+`・`-`・`!` | 符号と論理否定。`-X^2`は`-(X^2)` |
| 中置`nCk`・`nPk`・`nHk` | 組合せ・順列・重複組合せ |
| `*`・`/`・`%`・省略した乗算 | 乗除算・整数の剰余。左結合 |
| `+`・`-` | 加減算。左結合 |
| `<`・`<=`・`>`・`>=` | スカラーの大小比較 |
| `==`・`!=` | スカラーの等値比較 |
| `&&` | 真偽値の論理積。必要な場合だけ右辺を評価 |
| `\|\|` | 真偽値の論理和。必要な場合だけ右辺を評価 |
| `条件 ? 真の式 : 偽の式` | 選んだ枝だけを評価 |
| `引数 => 式` | ラムダ式。複数引数は`(a,n)=>式` |

`=`は定義や連立欄の等式、`==`は比較です。FPSを`==`で比較することはできません。[compare](#compare)を使います。`%`は整数スカラー専用で、負数の剰余は被除数と同じ符号です。0による剰余はエラーです。

### 乗算記号の省略

`2X`、`2F`、`2exp(X)`、`2(X+1)`、`(1+X)(1-X)`と書けます。省略しても通常の乗算と同じ優先順位です。

- `1/2X`は`(1/2)*X`、`2X^2`は`2*(X^2)`です。
- `FG`は1つの識別子です。積は`F*G`または`F G`とします。
- `F(1+X)`は呼び出しです。積なら`F*(1+X)`と書きます。
- 数値同士の積は`2*3`のように明示します。
- `5 nCk 2`と`nCk(5,2)`は同じ組合せです。旧表記`5C2`や`C(5,2)`は組合せ演算として解釈しません。

### 条件分岐とラムダ

`true`・`false`、スカラーの比較、`&&`・`||`・単項`!`を使えます。数値やFPSを真偽値へ自動変換しません。

`if(条件,真の式,偽の式)`は`?:`と同じ遅延評価です。例えば次数0で割る式を避けられます。ラムダは作成時の局所変数を捕捉し、入れ子にも対応します。ラムダの引数名に`a`・`n`等は使えますが、組み込み関数名・真偽値や重複する引数名は使えません。

```fps
fps(n=>n==0?1:1/n)
fps(n=>if(n%2==0,1,0))
!(2<1) && true
(3<2)?1/0:7
```

## 値と係数体

### 値の種類

| 型 | 例 | 意味 |
| --- | --- | --- |
| スカラー | `3`、`1/2`、`F[2]` | 単一の係数体上の値。係数列として0埋め表示しない |
| FPS | `fps(3)`、`exp(X)` | 負の次数を持たない通常の形式冪級数 |
| Laurent級数 | `1/X` | 有限個の負の次数を持つ形式級数 |
| ラムダ | `n=>n!` | 呼び出し・係数生成・map等に使う関数値 |
| 真偽値 | `true`、`2<3` | 条件・論理演算の値 |
| 解析レポート | `guess(...)`、`compare(...)` | 候補式・比較範囲等。FPSとして四則演算しない |

混合四則演算や微積分など、明示した規則ではスカラーを定数FPSへ昇格します。スカラーと定数FPSは同じ型ではありません。FPSを整数や真偽値へ暗黙に変換しません。

### 有理数と素数mod

- **有理数**: 分子・分母を整数で保持し、既約分数として表示します。浮動小数点近似はしません。
- **素数mod**: `2 ≤ p ≤ 2147483647`の素数を指定します。演算そのものを有限体で行い、係数を`0…p-1`で表示します。合成数は指定できません。
- スカラーはmod前の厳密な有理数も保持します。次数・添字・階乗・組合せの引数・比較・剰余はこの値を使うため、mod2でも次数2が次数0に変わりません。
- FPSから抽出した有限体の係数は、非負代表元を厳密値として使います。
- スカラーの除算も有限体上で行います。mod上で分母が0なら、整数上で約分できそうに見えてもその除算はエラーです。

### 精度とOGFとEGF

Nは絶対精度`O(X^N)`です。通常FPSでは次数0〜N-1、Laurent級数では負の次数も追加で表示します。Nは単なる表示項数ではありません。微分・除算・係数抽出等では必要な入力精度を自動で増やしますが、上限を超える場合はエラーです。

同じFPS`F=Σ c_n X^n`について、O.G.F.は`c_n`、E.G.F.は`a_n=n!c_n`を表示します。例えば`exp(X)`はE.G.F.表示で全項1です。式の評価・map・係数抽出は常に通常係数で行います。[egf](#egf)による生成と表示切り替えは別の操作です。

有限体のE.G.F.表示は必要な階乗が可逆な`N ≤ p`に限ります。負の次数を持つLaurent級数のE.G.F.表示は未対応です。

## 四則演算とべき乗

### 四則演算

`+`・`-`・`*`・`/`と単項`+`・`-`を使います。スカラー同士の結果はスカラー、FPSが混ざると定数FPSへ昇格します。通常の級数の積は係数列の畳み込みです。[Hadamard積](#数列変換)とは異なります。

分母の定数項が0でも、非零の先頭項からX因子を分離し、Laurent級数として除算できます。有限精度で全係数が0の分母を恒等的な0とは断定せず、内部精度の上限まで非零項を探します。

```fps
X/X
1/X
1/(X*(1-X))
(exp(X)-1)/X
X^(-2)*exp(X)
```

Laurent級数は四則演算・整数べき・逆元・微分・係数抽出・mapに対応します。積分はX^(-1)項が0の場合だけ可能です。負の項が相殺されれば通常FPSへ戻ります。

### べき乗

`F^k`の整数指数kはスカラー式で指定でき、負べきも扱います。0乗は1です。非零FPSの負べきはLaurent級数になることがあります。

`F^(p/q)`の一般の有理数乗は、底の定数項1のFPSを`exp((p/q)*log(F))`で計算します。分母2の有理数乗は平方根と整数べきへ帰着するため、先頭係数に根があり位数が偶数なら、定数項1以外の通常FPSにも対応します。

`F^G`は底の定数項1のとき`exp(G*log(F))`です。指数はスカラーまたは級数で、途中のlog・乗算・expの定義域を満たす必要があります。一般の超越定数や分数次数を必要とする結果は扱いません。

スカラーの有理数乗は厳密な有理数の根が存在する場合に対応し、根の次数は64以下です。分母2の場合は係数体内の平方根を使います。

```fps
(1+X)^(-3)
(1+X)^(1/3)
(4+X)^(3/2)
(1+X)^exp(X)
8^(1/3)
```

### sqrt

`sqrt(F)`は平方根です。スカラーにも対応します。有理数体では有理数として存在する根だけを返し、非負の根を選びます。素数modでは根が存在することを検証し、二つあれば小さい非負代表元を選びます。

通常FPSは最初の非零項の次数が偶数である必要があります。位数2mなら出力N項に入力N+m項が必要です。FPSの平方根は標数2に未対応です。Laurent級数の平方根やPuiseux級数は未対応です。

```fps
sqrt(9)
sqrt(1+X)
sqrt(X^2*(1+X))
```

## FPSを作る

### fps

`fps(lambda)`、`fps(lambda,lo)`、`fps(lambda,lo,hi)`で次数nに対する通常係数を生成します。lambdaは1引数でスカラーを返す必要があります。loとhiは両端を含み、lo省略時は0、hi省略時は無制限です。範囲外は定義上0で、ラムダは実行しません。lo>hiは零FPSです。

`fps(スカラー)`は定数FPSです。通常FPSも入力でき、スカラー/FPS入力には次数範囲を付けません。負の次数を含む入力は拒否します。

```fps
fps(n=>1/n!)
fps(n=>1/n,1,5)
fps(n=>nCk(2*n,n))
fps(3)
```

### egf

`egf(lambda)`、`egf(lambda,lo)`、`egf(lambda,lo,hi)`は重みa_nから`Σ a_n X^n/n!`を生成します。次数範囲と遅延評価はfpsと同じです。

`egf(seq(...))`や`egf(FPS)`は通常係数を重みとして取り込みます。スカラーは定数FPSになります。生成後は通常のFPSなので、積・map・係数抽出の規則は変わりません。

素数modでは、生成する各次数のn!が可逆である必要があります。分子が0でも0/0は解釈しません。範囲外ではラムダも階乗の除算も実行しません。

```fps
egf(n=>1)
egf(n=>n!)
egf(seq(1,2,6,24))
egf(n=>1/n,1,3)
```

最初はexp(X)、次は1/(1-X)、3番目は`1+2X+3X^2+4X^3`です。

### coeff

`coeff(F,k)`と`F[k]`は通常係数`[X^k]F`をスカラーとして返します。kは整数スカラーです。表示Nより高次でも追加精度で評価し、Laurent級数の負の次数も抽出できます。スカラーからの抽出はできません。

```fps
exp(X)[3]
coeff(exp(X),10)
coeff(1/X,-1)
```

### map

| 書式 | 変換の指定 |
| --- | --- |
| `map(F,式)` | 補助名aは現在の係数、nとiは添字 |
| `map(F,n=>式)` | 1引数ラムダには添字を渡す |
| `map(F,(a,n)=>式)` | 2引数ラムダには現在の係数と添字を渡す |

FはFPS/Laurent級数です。スカラーを変換したい場合はfpsで明示的に生成します。結果のn次係数は、指定式が返すスカラーです。`a[j]`は変換前の入力Fのj次係数です。名前付きFなら`F[j]`も使えます。隣接係数の参照には必要な精度を伝え、変換済みの係数は参照しません。明示したラムダの局所名は補助名より優先します。

Laurentの場合は入力の最低格納次数からN-1までを変換し、それより低い次数は0のままです。n/iは実際の整数次数なので負になる場合もあります。

```fps
F=1/(1-X)
map(F,a^2)
map(F,(a,n)=>(n+1)!*a^2)
map(F,(a,n)=>n*a[n+1]^2)
map(F,n=>n%2==0?F[n]:0)
```

### sum

`sum(lo,hi,k=>式)`は両端を含む有限総和です。ラムダは1引数で、各項はスカラー・FPS・Laurent級数です。全項がスカラーなら結果もスカラーです。lo>hiはスカラー0で、ラムダを実行しません。

`sum(lo,k=>式)`は上端を省略した無限和で、結果は通常FPSです。各項の位数が増大すると証明できる場合だけ有限化します。実数の解析的収束を判定する機能ではありません。開始添字は非負です。

```fps
sum(1,10,k=>k^2)
sum(0,6,k=>X^k/k!)
sum(1,k=>X^k)
sum(1,k=>X^(k^2))
```

### prod

`prod(lo,hi,k=>式)`は有限総積です。型・範囲・ラムダの規則はsumと同じで、空範囲はスカラー1です。

`prod(lo,k=>式)`は無限積です。各因子と1の差の位数が増大すると証明できる場合に計算し、結果は通常FPSです。整数分割などを数えられます。

```fps
prod(1,5,k=>k)
prod(1,5,k=>1+X^k)
prod(1,k=>1/(1-X^k))
```

無限演算は、`X^k`・`X^(2*k+1)`・`X^(k^2)`を含む項、積・微積分・一定の合成などから次数の下界を導きます。有限個の0を見て打ち切りません。任意の条件分岐や独自ラムダの内部まで証明するわけではないため、判定できない場合は有限範囲を指定してください。有限化後も項数上限があります。

### eulerTransform

`eulerTransform(F)`は定数項0の通常FPSを、`exp(Σ_{k>=1} F(X^k)/k)`へ変換します。Fのn次係数をc_nとすると、`∏_{n>=1}(1-X^n)^(-c_n)`に対応します。サイズごとの部品を多重集合へ変換する用途に使います。

```fps
eulerTransform(X/(1-X))
T=X*eulerTransform(T)
```

最初は分割数、Tはラベルなし非平面根付き木を数えます。素数modで必要な整数を割れなければエラーです。代表元を勝手に整数指数へ持ち上げません。小標数で整数指数の積を計算する場合は、上のprodによる直接の無限積を使える場合があります。

### inverseEulerTransform

`inverseEulerTransform(G)`は定数項1の通常FPSを受け取り、`G=∏_{n>=1}(1-X^n)^(-c_n)`を満たす`F=Σ_{n>=1} c_n X^n`を求めます。出力の定数項は0です。精度`O(X^N)`で復元するのに必要な入力精度も`O(X^N)`です。素数modでは`1,…,N-1`の逆元が必要なので、法pに対して`N ≤ p`で使えます。

```fps
P=prod(1,k=>1/(1-X^k))
inverseEulerTransform(P)
inverseEulerTransform(1+X)
```

2行目は`X/(1-X)`、3行目は`X-X^2`です。

## 基本関数

### exp

`exp(F)`は形式指数関数で、通常FPSの定数項0が必要です。スカラー引数は0だけに対応し、`exp(0)=1`をスカラーで返します。有限体では計算に必要な整数の逆元を要求します。特にexp(X)をN項求めるにはN≤pが必要です。

### log

`log(F)`は形式対数で、通常FPSの定数項1が必要です。スカラー引数は1だけに対応し、`log(1)=0`です。一般の対数定数やLaurent級数のlogは扱いません。

```fps
exp(X)
log(1+X)
exp(log(1+X))-1-X
```

### inv

`inv(F)`は乗法逆元1/Fです。スカラーにも対応します。FPSの定数項0でも非零ならLaurent級数として計算できます。零、または内部精度で非零項を確認できない入力はエラーです。

### compose

`compose(F,G)`はF(G(X))です。両引数は通常FPS、Gの定数項は0に限ります。通常FPSの`F(G)`も同じ呼び出しです。スカラーを渡す場合はfpsで明示的にFPSへ変換します。

```fps
F=1/(1-X)
compose(F,X+X^2)
F(X^2)
inv(X-X^2)
```

### revert

`revert(F)`はF(G(X))=Xを満たす合成逆関数Gです。Fは通常FPSで、定数項0・一次係数非零が必要です。invとは異なります。

次数nでは割らず、入力の一次係数で割ります。したがってmod2等でも一次係数が可逆なら、一律のN≤p制限なしで計算できます。精度1でも定義域の確認に必要な一次係数を別途評価します。

```fps
revert(X-X^2)
```

係数は`0,1,1,2,5,14,…`です。

```fps-mod2
revert(X-X^2)
```

このブロックは係数体をmod2にして使えます。

### diff

`diff(F)`はXでの微分です。スカラーは定数FPSへ昇格し、零FPSを返します。Laurent級数にも対応します。出力Nに必要な入力精度も要求するため、表示末尾の微分係数を失いません。高階微分は入れ子にします。

### integral

`integral(F)`は積分定数0の形式積分です。スカラーは定数FPSへ昇格します。Laurent級数ではX^(-1)の係数が非零だとlog(X)が必要なためエラーです。有限体で各次数の分母が可逆でない場合もエラーです。

```fps
diff(exp(X))
diff(diff(sin(X)))
integral(1/(1-X))
integral(1/X^2)
```

### Catalan

`Catalan`はカタラン数の母関数`1+X+2X^2+5X^3+…`です。単独でFPSとして参照できます。`Catalan(F)`は定数項0の通常FPSとの合成です。係数を整数上で生成してから写すため、組み込みの母関数自体は小標数でも計算できます。スカラー引数は0だけに対応し、`Catalan(0)=1`をスカラーで返します。

### LambertW

`LambertW(F)`はW exp(W)=F、W(0)=0の枝です。Fは定数項0の通常FPSです。係数を有理数で約分してから係数体へ写し、実際に必要な分母が可逆であることを検証します。スカラー引数は0だけに対応し、`LambertW(0)=0`です。

```fps
Catalan
Catalan(X^2)
LambertW(X)
T=X*exp(T)
T+LambertW(-X)
```

## 組合せ

整数上で計算してから係数体へ写すため、小さい素数でも階乗の逆元を使う公式へ置き換えません。引数はmod前の整数スカラーです。以下の0を返す範囲も、入力上限の検査には従います。

| 関数・書式 | 説明・境界 |
| --- | --- |
| `factorial(n)` / `n!` | 非負整数の階乗。0!=1 |
| `nCk(n,k)` / `binom(n,k)` / `n nCk k` | 二項係数。nは非負、k<0またはk>nでは0 |
| `nPk(n,k)` / `n nPk k` | n個からk個を順序付きで選ぶ。k<0またはk>nでは0 |
| `nHk(n,k)` / `n nHk k` | 重複組合せ。n>0ではbinom(n+k-1,k)。k<0では0、n=0ではk=0のときだけ1 |
| `stirling1(n,k)` / `s1(n,k)` | 符号なし第1種スターリング数。n要素の置換でサイクルがk個 |
| `stirling2(n,k)` / `s2(n,k)` | 第2種スターリング数。n要素をk個の空でない集合へ分割 |

Stirling数はnが非負で、(n,k)=(0,0)で1、n>0かつk=0では0、範囲外のkでも0です。

```fps
0!
factorial(5)
nCk(10,5)
5 nPk 2
nHk(0,0)
stirling1(4,2)
stirling2(4,2)
```

mod5でも`nCk(10,5)=2`を計算できます。

## 三角関数と双曲線関数

通常のTaylor展開は定数項0の通常FPSに適用します。一般の非零定数での値を近似しません。係数は有理数上で約分してから写し、実際に使う次数の分母を検証します。例えば疎な入力では不要な外側係数を計算しません。

### 三角関数

| 関数 | 意味・条件 |
| --- | --- |
| `sin(F)` | sinの原点展開。スカラー0には0 |
| `cos(F)` | cosの原点展開。スカラー0には1 |
| `tan(F)` | sin(F)/cos(F)。スカラー0には0 |
| `sec(F)` | 1/cos(F)。スカラー0には1 |
| `csc(F)` | 1/sin(F)。非零の入力に適用し、極を持つLaurent級数になる場合がある |
| `cot(F)` | cos(F)/sin(F)。非零の入力に適用し、極を持つ場合がある |

### 双曲線関数

| 関数 | 意味・条件 |
| --- | --- |
| `sinh(F)` | sinhの原点展開。スカラー0には0 |
| `cosh(F)` | coshの原点展開。スカラー0には1 |
| `tanh(F)` | sinh(F)/cosh(F)。スカラー0には0 |
| `sech(F)` | 1/cosh(F)。スカラー0には1 |
| `csch(F)` | 1/sinh(F)。非零の入力に適用し、極を持つ場合がある |
| `coth(F)` | cosh(F)/sinh(F)。非零の入力に適用し、極を持つ場合がある |

### 逆三角関数

| 関数 | 別名 | 形式的な枝・条件 |
| --- | --- | --- |
| `arcsin(F)` | `asin(F)` | 定数項0の入力、出力の定数項0 |
| `arctan(F)` | `atan(F)` | 定数項0の入力、出力の定数項0 |
| `arccos(F)` | `acos(F)` | 定数項1の入力、出力の定数項0。2*arcsin(sqrt((1-F)/2))の枝 |
| `arcsec(F)` | `asec(F)` | arccos(1/F)の枝。逆数の定数項1と平方根の条件が必要 |
| `arccsc(F)` | `acsc(F)` | arcsin(1/F)の枝。逆数の定数項0が必要 |
| `arccot(F)` | `acot(F)` | arctan(1/F)の枝。逆数の定数項0が必要 |

### 逆双曲線関数

| 関数 | 別名 | 形式的な枝・条件 |
| --- | --- | --- |
| `arcsinh(F)` | `asinh(F)` | 定数項0の入力、出力の定数項0 |
| `arctanh(F)` | `atanh(F)` | 定数項0の入力、出力の定数項0 |
| `arccosh(F)` | `acosh(F)` | 定数項1の入力、出力の定数項0。2*arcsinh(sqrt((F-1)/2))の枝 |
| `arcsech(F)` | `asech(F)` | arccosh(1/F)の枝。逆数の定数項1と平方根の条件が必要 |
| `arccsch(F)` | `acsch(F)` | arcsinh(1/F)の枝。逆数の定数項0が必要 |
| `arccoth(F)` | `acoth(F)` | arctanh(1/F)の枝。逆数の定数項0が必要 |

arccos/arccoshでは、平方根が整数次数・係数体内に存在することを検証し、根の符号はsqrtと同じ規則です。arccos(X)に必要なπ/2を捨てたり、arccos(1-X)に必要な分数次数を通常FPSとして解釈したりはしません。これらは対応する形式的な枝であり、実数・複素数の主値全体を計算する機能ではありません。

```fps
sin(X)^2+cos(X)^2
tan(X)
csc(X)
tanh(X)
arcsin(X)
arccos(1-X^2/2)
arccosh(1+X^2/2)
arccot(1/X)
```

## 数列と解析

数列専用の生成・変換は通常係数上で行います。変換関数は通常FPSを入力し、Laurentの負次数は扱いません。compareはLaurentにも対応します。解析レポートは係数体・条件・生成した式を表示し、「値をコピー」で内容をコピーできます。有理母関数のレポートは、復元式をノートへ追加できます。

### seq

`seq(a0,a1,...)`は係数を直接列挙したFPSです。入力後の係数は定義上0です。引数はスカラー式で、指定した個数も保持します。guessは、この0埋めを架空の検証項として増やしません。初期値や線形漸化式の係数にも使います。

### recurrence

`recurrence(count,initial,(a,n)=>式)`は一般漸化式から生成します。countは初期値の個数、initialは少なくともcount個の係数を持つ通常FPSです。nは生成する項の添字、a[j]は0≤j<nの確定済みの過去項だけを参照できます。ラムダは2引数です。

履歴a自体の四則演算・負添字・未来参照はできません。整数の添字・条件式はmodで変わりません。

### linrec

`linrec(k,c,initial)`は定係数線形漸化式です。`a_n=Σ_{j=0}^{k-1} c[j]*a_(n-1-j)`として、係数は直前の項から順に指定します。cとinitialは少なくともk個の係数を持つ通常FPSです。

### rationalGF

`rationalGF(k,c,initial)`はlinrecと同じ引数から通常母関数P/Qを厳密に復元するレポートです。初期値と漸化式の説明を含みます。

```fps
seq(1,2,3)
recurrence(2,seq(0,1),(a,n)=>a[n-1]+a[n-2])
linrec(2,seq(1,1),seq(0,1))
rationalGF(2,seq(1,1),seq(0,1))
```

### pRecursive

`pRecursive(initial,p0,p1,...,pr)`は、n≥0で`Σ_{j=0}^r p_j(n)*a_(n+j)=0`を満たす数列を生成します。initialに少なくともr個の初期係数を指定します。最高シフトの係数が0なら、その添字で先の項を一意に決められない理由を表示します。

係数多項式の中だけはx/Xが添字nを表します。整数・x・四則演算（除算は定数多項式のみ）・非負整数べき・係数列としてのseq・同じ多項式構文の名前参照を使えます。

### pRecGF

`pRecGF(initial,p0,p1,...,pr)`は同じ漸化式から通常母関数Fの微分方程式を復元するレポートです。初期値に由来する境界項を含め、全項に共通のx因子だけを除きます。作用素の最小性や特異点での解の一意性は保証しません。復元できることと、その方程式を連立欄で解けることは別です。

```fps
pRecursive(seq(1),-1,1+X)
pRecursive(seq(1),-1-X,1)
pRecGF(seq(1),-1,1+X)
pRecGF(seq(1),-1-X,1)
```

最初の数列はexp(X)、次は階乗を通常係数に持つFPSです。対応する方程式はF'-F=0と、(1-X)F-X^2 F'=1です。

### guess

`guess(F,training,maxOrder)`は、先頭training項だけを学習して定係数線形漸化式の候補を探し、残りの項で検証します。Fは通常FPSまたはseqです。trainingは2〜63、検証には少なくとも1項必要です。低次数から探し、一意な候補だけを採用します。

候補なし・情報不足・検証不一致もレポートにします。検証項を次数選択や係数決定には使いません。一致しても無限級数の恒等性の証明ではありません。

```fps
Data=seq(0,1,1,2,3,5,8,13)
guess(Data,4,3)
```

### compare

`compare(F,G)`は指定精度まで通常係数を比較し、最初に異なる次数と両係数、または比較した範囲での一致をレポートにします。両引数はFPS/Laurent級数で、負の次数も比較対象です。一致を無限級数の証明と解釈しません。

```fps
compare(1/(1-X),fps(n=>1))
compare(1/X,1/X+X)
```

### 数列変換

Fの通常係数をa_n、Gの通常係数をc_nとします。

| 関数 | 結果のn次係数b_n |
| --- | --- |
| `partialSums(F)` | a_0+…+a_n |
| `binomialTransform(F)` | Σ_{k=0}^n binom(n,k)*a_k |
| `inverseBinomialTransform(F)` | Σ_{k=0}^n (-1)^(n-k)*binom(n,k)*a_k |
| `hadamard(F,G)` | a_n*c_n。係数ごとの積 |
| `even(F)` | a_(2n)。次数は0から詰め直す |
| `odd(F)` | a_(2n+1) |
| `extract(F,m,r)` | a_(mn+r)。1≤m≤16、0≤r<m |

項抽出は出力N項に必要な入力の高い次数も要求します。必要な内部精度が上限を超える場合はエラーです。evenとは異なり、`map(F,(a,n)=>n%2==0?a:0)`は元の次数を保ちます。

```fps
F=X/(1-X-X^2)
partialSums(F)
binomialTransform(F)
inverseBinomialTransform(binomialTransform(F))-F
hadamard(F,F)
even(F)
odd(F)
extract(F,3,1)
```

## 循環定義と連立系

### 通常行の再帰定義

名前が自分自身や別の行を参照する循環を解析し、対応する解法で通常FPSとして解きます。行順には依存しません。解いた級数は他の行から微分・除算・係数抽出等で使え、必要精度を循環全体へ伝えます。

```fps
F=1+X*F^2
T=X*exp(T)
U=1+X*V
V=1+X*U*V
```

FはCatalan、Tはラベル付き根付き木のEGFです。定数項は一意な線形条件だけ自動推定します。複数の定数解がある`F=F^2+X`等では、各行の「再帰の初期値」に0または1を入れて枝を選びます。初期値は解く未知数から独立したスカラー式で、外部の名前も使えます。微積分系・次数依存系の初期係数にはseqも使えます。非循環の行では初期値欄を使いません。

### 明示的な連立方程式

「＋ 方程式グループを追加」で、未知数と方程式をそれぞれ1行ずつ入力します。未知数の個数と方程式の本数は揃えます。

未知数と定数項:

```text
u=1
v=0
```

方程式:

```text
u^2+v=1+X
u-v=1
```

定数項の自動推定には`u`のように名前だけを入力し、`u=`とは書きません。未知数を通常定義や他グループと重複させません。`=`は等式で、比較の`==`とは異なります。グループをまたぐ相互依存もまとめて解析します。

解法は「自動 / 係数を次数順に求める / Newton法」です。正則な代数系では定数Jacobianの可逆性と初期値・代入残差を検証します。自動では対応する収縮系に固定点反復、それ以外の低い精度に係数逐次法、16項以上にNewton法を選びます。微積分系と次数依存系は専用の係数逐次法を使います。

結果の未知数をクリックすると通常行へ追加し、係数表・数式・コピーで確認できます。名前参照・ラムダ展開・定義域に従う四則演算・整数べき・exp/log/sqrt・特殊級数などを含む正則系に対応します。任意の作用素を点ごとのJacobianで解けるわけではありません。

### 微積分の再帰とODE

```fps
F=1+integral(F)
G=integral(1+G^2)
```

Fはexp(X)、Gはtan(X)です。`F=diff(F)`のような微分再帰では再帰初期値に1等を指定します。

連立欄の未知数を次のように指定できます。

```text
s=0
c=1
```

方程式:

```text
diff(s)=c
diff(c)=-s
```

解はsin(X)とcos(X)です。高階の例は、未知数`u=seq(0,1)`、方程式`diff(diff(u))=-u`です。初期係数a_kは通常係数であり、微分値u^(k)(0)そのものではありません。r階微分には原則a_0…a_(r-1)を指定します。未知数から独立な初期値を使い、欠けた係数を推定できない場合は入力を求めます。

微分と代数式の混在、積分を介する相互再帰も扱います。最高階微分の未確定定数に非線形な方程式では、根を自動選択しません。例えば`(diff(u))^2=1`には`u=seq(0,1)`等で追加の初期係数を指定します。

### 次数依存の循環

下の次数から一意に決定できる定義は、合成・map・総和/総積・Euler変換・ラムダ・revert等を含んでも係数依存で計算します。左辺が未知数1つの明示連立にも適用します。

```fps
F=1+diff(X^2*F)
G=1+X*G(X^2)
H=1+X*sum(1,k=>X^k*H(X^k))
R=X+X*revert(R)
A=fps(n=>n==0?1:n*A[n-1])
B=1+X*map(B,a^2)
```

例えばdiff(X^2*F)のn次に必要なのはFのn-1次です。同次数の依存も、循環しなければ要求順に確定します。未確定の同一係数への再入や未来参照は拒否します。既知の初期係数と残差を検証し、未確定部分を0で埋めて解いたことにはしません。

`F=1+X*sum(1,k=>F(X^k))`は非零定数項を無限に足すため収束しません。`X^k*F(X^k)`や`F(X^k)-F[0]`のように次数の増大を証明できる項を使う必要があります。

一般の特異系・非因果的な関数方程式・高指数の微分代数系・Laurent/Puiseux解は未対応です。特異な系を「解なし」と断定せず、現行解法で確定できない理由を表示します。小さい素数modではJacobianと実際に必要な分母をその体上で検証します。

## 画面操作

ヘッダーの「ドキュメント」はこのリファレンスを開き、「GitHub」はソースリポジトリを別タブで開きます。

### 行と入力パネル

- Enterで、編集中の行の直後に空行を追加し、新しい入力へ移動します。補完中はEnterで候補を確定し、IME変換中は行を追加しません。
- 追加ボタン・結果からの式追加・画面下のレシピからの追加は末尾です。
- 行の「⧉」は元の直後へ新規IDで複製します。式・初期値・コメントをコピーし、独立して編集できます。定義名もコピーするため、複製後に別名へ変えて重複を解消します。
- 「×」で削除します。最後の行を消した場合は空行を残します。
- 専用取っ手のドラッグで並べ替えます。マウス・タッチに対応し、端では入力側を自動スクロールします。Escapeやpointercancelでキャンセルします。
- 取っ手にフォーカスして↑↓・Home/Endでも並べ替えられます。行ID・選択結果・入力位置を維持します。
- 入力パネルの拡大ボタン、境界の左右ドラッグで幅を変更します。境界にフォーカスして←→、Shift付きで大きく移動、Home/Endでも変更できます。ダブルクリックで標準幅へ戻します。
- 長い式は行内で横スクロールし、カーソル位置へ追従します。入力と結果の縦スクロールは独立しています。
- 狭い画面は入力と結果を上下に分割します。各パネルをフォーカスするとPage Up/Down等のキーでもスクロールできます。

### 入力支援

関数名・定義済み名・ラムダ引数を補完します。Ctrl/⌘+Spaceで明示的に開けます。↑↓で選び、Enter・Tab・クリックで確定、Escapeで閉じます。関数の括弧を挿入し、中へカーソルを置きます。補完確定も独立したundo対象です。

通常行・再帰初期値・連立欄で構文ハイライト、対応括弧と不一致、得られるエラー位置を表示します。診断メッセージのクリックで該当位置を選択します。連立全体の解法エラーなど、位置を特定できないエラーは結果欄へ表示します。

### コメント

各行の「コメント」は説明やメモの複数行入力です。数式の構文・TeXとして実行しません。Enterは改行になります。保存・JSON・共有URL・複製・並べ替え・undo/redoに含み、編集だけでは再計算しません。

### undoとredo

「元に戻す」「やり直す」、Ctrl/⌘+Z、Ctrl/⌘+Shift+Z、Ctrl/⌘+Yを使えます。式・コメント・行操作・再帰初期値・連立設定・係数体/N/mod/基底の変更が対象です。

同じ欄の短時間の連続入力は集約し、貼り付け・フォーカス/カーソル移動・IME確定等で区切ります。undo後に新しく編集するとredoの分岐を破棄します。履歴はタブ内だけで、再読み込みやJSONには持ち越しません。

単なる行選択・幅変更・係数表/級数表示の切り替えは履歴を増やしません。ノート読み込みは全体で1回のundo対象で、その場合は表示形式も復元します。

### 数式と結果の表示とコピー

入力式を構文木からTeXへ変換し、KaTeXで表示します。入力欄はこの式言語用であり、TeXを直接入力する欄ではありません。「TeXソース」で文字列を確認できます。

「級数」は横向きの展開とO(X^N)を表示します。Laurentでは負の次数も含み、O項は絶対精度のままです。スカラーにはO項を付けません。

| 操作 | 内容 |
| --- | --- |
| 係数をコピー | 通常FPSは`[1, 1/2, ...]`という通常係数またはEGF表示係数の配列テキスト |
| Laurentの係数をコピー | `{"startDegree":-1,"coefficients":["1","0",...]}`という最低次数付きJSON |
| 値をコピー | スカラー・真偽値・ラムダ・解析レポートの表示値 |
| TeXをコピー | 入力式と、得られている場合は結果のTeX |

係数コピーは有理数を`1/2`の形で保持するテキストであり、通常FPSの配列が常にJSONの数値配列になるとは限りません。

### OEISで整数係数列を検索

結果欄の「OEISで検索 ↗」は、選択した級数の整数係数をコンマでつなぎ、OEISの検索結果を別タブで開きます。現在のO.G.F. / E.G.F.表示の係数を、先頭の0や負の符号も含めて表示順にすべて渡します。Laurent級数は最低次数から、素数modでは画面に出る剰余をそのまま検索します。

結果が級数で、表示係数がすべて整数の場合にリンクが表示されます。OEISへの送信はリンクを開いたときに行われます。検索語が長いときや候補が見つからないときは、打ち切り次数Nを小さくするか、OEISの検索欄で項を調整してください。

## 保存と共有

### ブラウザ保存

式・コメント・行順・再帰初期値・連立設定・計算設定・表示形式・入力幅を、このブラウザのlocalStorageへ保存します。保存できない環境でもタブ内の計算は可能です。自動同期はありません。履歴は永続化しません。

### JSON保存と読み込み

「保存・共有・名前変更」からJSON保存・JSON読み込みを使います。既定の保存ファイル名はfps-notebook.jsonです。保存形式はversion:1で、行順・式・コメント・初期値・連立・係数体・N・mod・基底・表示形式を含みます。ID・入力幅・履歴は持ち出しません。旧version:1ノートにも対応します。

読み込みはノート全体を置き換えます。検証は反映前に行い、不正データで途中まで変更しません。読み込み前の内容は1回のundoで復元できます。編集中の構文エラーを含むノートもバックアップできます。

### URL共有

同じノートをURLの`#notebook=…`へ格納します。作成時に外部サーバーへノートを送信しません。リンクを持つ相手は式・コメント・設定を読めます。長すぎる場合はJSONを利用します。

「共有URLを作成」でリンクを表示し、「URLをコピー」でコピーします。クリップボードを利用できない場合はURLを選択し、手動でコピーできるようにします。

リンクを開いたときの復元もundo対象です。復元成功後はフラグメントを消し、以後の再読み込みではその後の編集を維持します。

### 変数名の一括変更

グローバルな定義と自由参照、再帰初期値、連立未知数・方程式を一括変更します。部分文字列や同名の局所ラムダ引数は変えません。変更元は1回だけ定義されている必要があります。

予約語・重複名・局所変数への捕獲・構文不正・上限超過・名前付きmapの補助名iの束縛を変える変更は拒否し、部分反映しません。全体が1回のundo対象です。

## サンプル集

分類・検索・説明付きプレビューからノートを読み込めます。題名・説明・式・コメントを検索し、空白で区切った複数語はAND条件です。文字の全角/半角等を正規化して比較します。

読み込みは現在のノートを置き換え、1回のundoで戻せます。各式のコメントに定義・添字・表示基底・使い方・出典を記載しています。パラメータは通常のスカラー定義行を編集します。

現在は5分類・52件です。既定は有理数・N=12、木やグラフ等はN=8〜10で、代表級数を先頭に置いています。

| 分類 | 登録内容 |
| --- | --- |
| 漸化式（10件） | 等差・等比・Fibonacci・Lucas・Tribonacci、タイル敷き、順序付き整数分割、OGF/EGF、数列変換、推測/比較 |
| 組合せ論（20件） | Montmort・Bell・Bernoulli・分割・Catalan・Franel・Catalan convolution・中央/ずれた二項係数・交代順列・Motzkin・Delannoy・Narayana・大小Schröder・Stirling列・対合・完全マッチング・順序付きBell・サイズ制限付き集合分割・条件付き整数分割 |
| 木（6件） | 平面木、ラベル付き/なしの根付き木・自由木・森、写像グラフ |
| グラフ（10件） | 全/連結無向、なもり、連結オイラー、二部、橋なし連結、二重連結ブロック、全有向、DAG、強連結有向、トーナメント |

BernoulliはB_1=-1/2、Catalan convolutionはCatalan^rの通常畳み込み、ずれた二項係数はbinom(2n,n+r)です。Narayanaと一般のDelannoyは一方の添字を固定します。交代順列の最初の不等号と大小Schröderの規約もコメントで明示します。

本文は`samples/tree/*.json`等の保存用JSON、メタデータは`samples/index.json`で管理します。個別JSONは通常のJSON読み込みでも開けます。

| 表示精度N / 必要な内部絶対精度 | 1〜64 / 512 |
| Laurentの最低次数 / 係数抽出の添字 | -128 / -128〜127 |
| 整数べき・総和/総積の添字 / 生成次数範囲 | ±10000 / 0〜10000 |

内部精度不足の引数を、未知の高次係数0で埋めて計算することはありません。重い計算はWorkerで行い、入力更新時に古いWorkerを破棄します。

一般のFPSをラムダの引数へ渡した後、その局所引数にdiff等で追加精度を要求すると、渡した時点の精度が足りずエラーになる場合があります。必要な演算を入力式の側で済ませるか、元の式を名前参照できる形にしてください。係数生成・mapのスカラー引数や名前参照には必要精度を伝播します。

## エラーと非対応範囲

- **名前や構文**: 未定義名・重複定義、予約語への代入、関数の引数数、括弧の不一致、対応しない文字等を確認してください。
- **型**: スカラー・FPS・真偽値・ラムダ・解析を区別します。係数が必要ならF[k]、定数FPSが必要ならfps(...)を使います。
- **分母と標数**: mod上の0除算、exp/log/積分/egf等で必要な整数の逆元、根の存在を確認します。整数上の式を途中でmodの0除算にしていないか注意してください。
- **精度**: 微分・Laurentの積/商・根・隣接係数map・項抽出等では表示Nより高い精度が必要です。Nや極の次数を下げてください。
- **循環**: 初期係数不足、枝の不整合、未確定な同次数や未来への参照、対応しない作用素を確認します。特異性を解なしと断定する診断ではありません。
- **無限演算**: 各項、または各因子と1の差の次数が増大することを証明できる形にします。証明できない場合は有限範囲にします。
- **超越定数と分数次数**: 一般のexp/log/三角関数の非零定数での値、π等の定数、Puiseux級数は扱いません。
- **計算範囲**: 多変数、一般の非因果的な関数方程式、特異系全般、Laurent/Puiseux級数を未知解とする方程式は未対応です。
- **時間と環境**: 時間超過では項数や式を小さくします。Workerやブラウザ保存が使えない環境の診断も表示します。

```fps-error
sqrt(2)
exp(1)
log(X)
arccos(X)
compose(exp(X),1+X)
integral(1/X)
```

これらは既定の有理数体ではエラーとなる例です。
