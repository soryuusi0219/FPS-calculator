# FPS-calculator

競技プログラミング向けの形式冪級数（FPS）計算ノートです。TypeScript + Vite で作成し、計算はブラウザの Web Worker 内で行います。サーバーやAPIキーは不要です。

Desmosのように左側へ式や変数定義を並べ、右側で選択した式の係数を確認できます。まず正しさを確認できる小規模な実装を用意し、高速化や暗黙方程式を段階的に追加するための骨格です。

## 起動

Node.js 24以上とnpmを使用します（`.nvmrc` は24）。

まず `node --version` を確認してください。nvmを利用している場合は `nvm install` → `nvm use` で切り替えられます。

Linux/macOSでNode.jsが古い場合は、次の手順でプロジェクト専用のNode.jsを導入できます。

```sh
bash scripts/setup-node.sh
export PATH="$PWD/.local/node/bin:$PATH"
npm ci
npm run dev
```

セットアップはNode.js公式配布のSHA-256を検証し、Git管理外の `.local/node/` に配置します。システムのNode.jsやシェル設定は変更しません。導入後は、元のNode.jsが古いシェルからでも `npm run dev` などのプロジェクトコマンドが `.local/node/` を自動的に選びます。`npm ci` / `npm install` 自体には上記のPATH設定またはバージョン管理ツールによる切り替えが必要です。

Node.js 24以上が既に利用できる場合は、通常どおり起動できます。

```sh
npm ci
npm run dev
```

表示されたローカルURL（通常 `http://127.0.0.1:5173`）をブラウザで開きます。`index.html` の直接オープンではなく開発サーバーを使用してください。

```sh
npm run check    # TypeScriptの型検査
npm test         # 係数・恒等式・精度・エラー条件のテスト
npm run build    # 型検査と静的ファイル生成（dist/）
npm run preview  # ビルド結果のローカル確認
```

Vite内で `SyntaxError: Unexpected token '.'` が出る場合は、古いNode.jsでViteを起動している可能性があります。`.nvmrc` と `engines` は自動ではNode.jsを切り替えません。上記のセットアップまたはnvmによる切り替えを実施してください。起動スクリプトもバージョンを確認し、対応するNode.jsが見つからなければセットアップ方法を表示して停止します。

`dist/` を静的ホスティングすればブラウザだけで動作します。サブパスへの配置では Vite の `base` を配信先に合わせて設定してください。KaTeXと数式用フォントも同梱し、実行時のCDN・外部APIへのアクセスはありません。

## 使い方

1行に1つの式、または `名前 = 式` を入力します。別の行の定義は前方参照も可能です。行番号または入力欄を選択すると係数表が切り替わります。Enterで行を追加できます。

長い式の入力には次の操作を使えます。

- **入力欄を広げる**: ボタンで入力側を拡大できます。デスクトップでは入力欄と結果欄の境界を左右にドラッグして幅を調整できます。境界にフォーカスして左右キー（Shiftで大きく移動）、Home/Endでも調整でき、ダブルクリックで標準幅へ戻ります。
- **横スクロール**: 式の長さに合わせて入力要素が伸び、各行に横スクロールが現れます。カーソル移動時は編集中の位置が見えるように追従します。スマートフォンでも各行を横へスクロールできます。
- **行の並べ替え**: 行頭の取っ手をドラッグして、挿入線の位置にドロップします。マウス・タッチに対応し、取っ手にフォーカスして上下キーやHome/Endでも移動できます。ドラッグ中にEscapeを押すとキャンセルします。
- **式の複製**: 各行の「⧉」ボタンで、同じ内容の式を直後に追加し、複製した入力欄へ移動します。元の式とは独立して編集でき、30行の上限では複製できません。名前付き定義もそのままコピーするため、複製後に名前を変更してください。同じ名前の定義がある間は重複エラーを表示します。

入力側の幅と行順はブラウザに保存します。並べ替えでも選択した式・入力位置・係数結果を維持します。画面が狭い場合は幅を自動調整し、スマートフォンでは上下に並ぶレイアウトと行内スクロールを使います。

「元に戻す」「やり直す」ボタンで編集履歴を操作できます。ショートカットは **Ctrl/⌘ + Z**（undo）、**Ctrl/⌘ + Shift + Z** または **Ctrl + Y**（redo）です。式の編集・追加・削除・複製・並べ替えと、係数体・打ち切り次数・mod・O.G.F./E.G.F.の変更が対象です。行の選択、入力幅、係数表/級数の表示切り替えは履歴に含めません。

最大100操作を保持し、同じ入力欄で1秒未満の間隔で続けた入力はまとめて戻します。カーソル・フォーカス移動や全選択で入力を区切り、貼り付け・切り取りも独立した操作として扱います。IME入力は変換の確定時に1操作として記録・計算します。undo/redoでは行ID・行順・選択と、数式入力のカーソル位置・選択範囲・横スクロールも復元します。undo後に新しく編集するとredo履歴を破棄します。復元した式と設定は再計算・自動保存されます。履歴自体はタブ内のみで保持し、再読み込み後は保存済みの内容から新しく始まります。

### 保存・共有・編集支援

「保存・共有・名前変更」を開くと、JSON保存・JSON読み込み・共有URLの作成・変数名変更を使えます。

- **JSON保存/読み込み**: 行順、式、再帰の初期値、連立未知数・方程式・解法、係数体、mod、次数、OGF/EGF、係数表/級数の表示形式を保存します。最大256 KiBで、読み込み前に全体の形式と入力上限を検証します。編集中の式も保存できます。読み込みはノート全体を置き換え、1回のundoで元に戻せます。行ID・入力パネル幅・履歴は持ち出しません。従来のversion:1のブラウザ保存JSONも読み込めます。
- **URL共有**: 同じノートをURLの `#notebook=…` 部分に格納し、リンクを開いたブラウザで復元します。URL作成時にサーバーへノートを送信しません。URLを持つ相手は式と設定を読めます。上限は12,000文字で、超える場合はJSONを使ってください。復元もundo対象です。復元後はフラグメントを消し、再読み込みではその後の編集を維持します。
- **補完**: 関数名・定義済み名・ラムダ引数を入力中に候補を表示します。Ctrl/⌘ + Spaceでも開けます。↑↓で選び、Enter/Tabまたはクリックで確定、Escapeで閉じます。候補がある間のEnterは補完を確定し、それ以外では従来どおり行を追加します。関数補完では括弧を挿入して中にカーソルを置きます。確定は独立したundo対象です。
- **ハイライトとエラー**: 通常行・再帰初期値・連立欄でトークンを色分けし、カーソル付近の対応括弧と不一致を示します。構文エラーと位置が得られる評価エラーは下線・列番号（複数行では行番号も）を表示し、メッセージをクリックすると該当位置を選択します。連立系全体の解法エラーなど、特定箇所に対応しないエラーは従来の結果欄に表示します。
- **名前変更**: グローバルな定義・自由参照・再帰初期値・連立未知数と方程式をまとめて変更します。部分文字列や同名のラムダ引数は変更しません。予約語、重複名、変更後の局所変数への捕獲、構文エラーが残る欄、文字数超過、名前付きmap変換の補助名 `i` の束縛が変わる変更は拒否し、途中まで変更しません。変更元は1回だけ定義されている必要があります。変更全体を1回のundoで戻せます。

「サンプル集」には組合せ論・漸化式・木・連立系の分類、検索、プレビューと読み込みの枠を用意しています。現在のカタログは空で、サンプル内容・テンプレート本体はまだ追加していません。既存の初期ノートと入力レシピは維持しています。

```text
f = 1/(1-x)
g = exp(x)
h = revert(x-x^2)
compose(f, x+x^2)
diff(f)
map(f, n^2)
sqrt(1+x)
(1+x)^(1/3)
(1+x)^exp(x)
k = coeff(f,5)
c = n => nCk(2*n,n)
fps(c)
map(f, (a,i) => (i+1)!*a^2)
map(f, (a,i) => i*f[i+1]^2)
fps(n => n%2==0 ? 1 : 0)
1/x
inv(x-x^2)
(exp(x)-1)/x
coeff(1/x,-1)
Catalan
LambertW(x)
F = 1/(1-X)
2F+3X
```

| 入力 | 意味・条件 |
| --- | --- |
| `+ - * /`、括弧、単項 `+ -` | スカラー同士はスカラー。FPSとの混合では定数FPSへ昇格。級数の非零の分母はLaurent級数として除算 |
| `f^k` | 整数スカラー式 `-10000 ≤ k ≤ 10000`。`x^(2+1)` や変数の指数も可。非零の底の負べきもLaurent級数として計算 |
| `sqrt(f)` | 係数体内の厳密な平方根。FPSは偶数の位数、先頭係数が平方剰余であることが必要。標数2のFPSは未対応 |
| `f^(p/q)` | 定数項1のFPSに対する有理数乗。分母2は平方根と整数べきで計算し、定数項1以外や正の偶数位数にも対応 |
| `f^g` | `f(0)=1` のとき `exp(g*log(f))`。gはスカラーまたはFPS |
| `exp(f)` | `f(0)=0` |
| `log(f)` | `f(0)=1` |
| `Catalan` / `Catalan(f)` | カタラン数の母関数 `1+x+2x^2+5x^3+…`。引数付きでは `f(0)=0` のFPSを合成 |
| `LambertW(f)` | `W*exp(W)=f`、`W(0)=0` を満たす形式級数。`f(0)=0` が必要 |
| `inv(f)` | 乗法逆元 `1/f`。定数項0でも非零の級数ならLaurent級数として計算 |
| `compose(f,g)` | `f(g(x))`。`g(0)=0` |
| `revert(f)` | `f(g(x))=x` となる合成逆関数。`f(0)=0`、`[x]f≠0` |
| `diff(f)` | 微分。必要な入力精度も自動で増やす |
| `integral(f)` | 定数項0の積分。非零のx^(-1)項はlog(x)が必要なためエラー |
| `f[k]` / `coeff(f,k)` | 通常係数 `[x^k]f` をスカラーとして返す。表示より高次も取得可。Laurent級数の負の次数も抽出可 |
| `fps(n => 式)` | 次数nから通常係数を生成。`fps(3)` は定数FPS |
| `map(f,a^2)` | 各通常係数aと添字n（別名i）に式を適用 |
| `map(f,n => 式)` | 1引数ラムダは添字を受け取る |
| `map(f,(a,n) => 式)` | 2引数ラムダは現在の係数と添字を受け取る |
| `n!` / `factorial(n)` | 非負整数の階乗 |
| `nCk(n,k)` / `binom(n,k)` | 二項係数。`5 nCk 2` も可 |
| `nPk(n,k)` | 順列。`5 nPk 2` も可 |
| `nHk(n,k)` | 重複組合せ。`3 nHk 2` も可。`nHk(0,0)=1` |
| `stirling1(n,k)` / `s1(n,k)` | **符号なし**第1種スターリング数 |
| `stirling2(n,k)` / `s2(n,k)` | 第2種スターリング数 |
| `条件 ? 真の式 : 偽の式` / `if(条件,真,偽)` | 選択した枝のみを評価 |
| `< <= > >= == !=`、`&& || !`、`%` | スカラーの比較、真偽値の論理演算、整数の剰余 |

数値は整数リテラルです。有理数は `1/2` のように入力してください。変数は `x`（`X`も可）、名前はASCII英字または `_` から始まる識別子です。`x`, `X`, `a`, `n`, `true`, `false`, `Catalan` と組み込み関数名は定義文の予約語です。ラムダの局所引数にはnやaを使えます。`C`・`P`・`H` は予約語ではなく変数名・ラムダ名に使えます。旧構文の `C(5,2)`・`5C2` 等は組合せ演算としては扱いません。保存済みの式も `nCk(5,2)` 等へ変更してください。

`2X`、`2F`、`2exp(x)`、`2(x+1)`、`(1+x)(1-x)` のように乗算の `*` を省略できます。`FG` は1個の識別子であり、FとGの積には `F*G` または `F G` を使います。名前・関数呼出しの直後の括弧は呼出しとして扱うので、FPSのFと括弧内の式を掛ける場合は `F*(1+x)` としてください。数値同士には `2*3` と書きます。

`-x^2` は `-(x^2)`、`(-x)^2` とは区別します。べき乗は右結合、後置階乗はべき乗より先に計算します。組合せの中置演算 `nCk` / `nPk` / `nHk` は乗除算より先に計算します。省略した乗算は `*` と同じ優先順位・左結合です。`1/2X` は `(1/2)*X`、`2X^2` は `2*(X^2)` です。

## 循環定義・連立方程式

通常の数式行で、次のような再帰定義を解けます。解はFPSとして扱い、行の順序には依存しません。

```text
f = 1+x*f^2
g = x*exp(g)
u = 1+x*v
v = 1+x*u*v
```

`f` は `Catalan`、`g` は `-LambertW(-x)` と一致します。定数項は一意に決まる線形条件から自動推定します。例えば `f=f^2+x` のように複数の定数解がある場合、各行の **再帰の初期値** を開いて `0` または `1` を指定してください。初期値には、未知数から独立したスカラー式（外部のスカラー名も可）を使います。非循環の定義ではこの欄を使用しません。

一般の方程式は **＋ 方程式グループを追加** から入力します。例えば次の2つの欄を設定します。

未知数と定数項（1行に1個）:

```text
u = 1
v = 0
```

方程式（1行に1本）:

```text
u^2+v = 1+x
u-v = 1
```

定数項の自動推定には `u` のように名前だけを入力します。`u =` とは書きません。未知数と方程式の個数は揃え、未知数は通常の定義や他のグループと重複させないでください。方程式の `=` は等式で、真偽値の `==` と区別します。結果ボタンをクリックすると、その未知数を通常の数式行へ追加して係数表・TeX・コピー等を利用できます。別の行から `u`、`diff(u)`、`u[20]`、`1/u` のように参照することもできます。

解法は **自動 / 係数を次数順に求める / Newton法** を選べます。自動では収縮が確認できる系に固定点反復を使い、それ以外は小さい精度で係数逐次法、16項以上でNewton法を使います。計算は指定された係数体で厳密に行い、初期値の整合性・定数Jacobianの可逆性・元の式への代入残差を検証します。

対応範囲は、通常FPS上で定数項の近傍に形式展開でき、定数Jacobianが可逆な系です。未知数に対する四則演算（分母の定数項は非零）・整数べき・`exp`・`log`・非零定数項の `sqrt`・`Catalan`・`LambertW`・`fps` に対応します。一般のFPS乗は底の定数項1でexp/logへ帰着します。名前付き・直接ラムダの呼出しも、対応演算へ展開できる場合に扱います。未知数と独立した条件の分岐は選んだ枝だけを解釈します。

未知級数の合成・map・係数抽出を**方程式内部の循環に含める**場合、Jacobianが特異な場合、Laurent/Puiseux級数の解は未対応として診断します。既に解けた級数に対して、外側から微分・除算等を行う機能は利用できます。必要精度は循環グループ全体へ伝播します。特異なJacobianは「解なし」とは断定せず、判定できない旨を表示します。

素数modではその体上でJacobianと分母を検証します。多項式の系には一律の `N ≤ p` 制限はありませんが、exp/log等の個別の分母・標数条件は維持します。グループをまたぐ相互依存もまとめて解きます。上限は4グループ、1グループおよび結合後の循環全体で未知数8個、各欄4096文字、方程式1本512文字です。未知数と初期値・方程式・解法は保存とundo/redoの対象です。

## スカラー・ラムダ・map

`k=5!` はスカラー、`f=1/(1-x)` はFPS、`1/x` はLaurent級数、`c=n=>n!` はラムダです。結果には型ラベルを表示し、スカラーをゼロ埋めの係数列として表示しません。スカラーをFPSにするには `fps(k)` と入力できます。階乗や組合せの引数、添字、次数条件には整数スカラーを使い、級数から整数が必要なときは係数を抽出します。

係数抽出とmapは、O.G.F./E.G.F.の表示設定にかかわらず**通常係数**を扱います。`exp(x)[3]` は常に `1/6`。ラムダは名前に代入して呼べ、`c(4)`、`fps(c)`、`map(f,c)` のように使えます。ラムダは作成時の局所変数を保持します。生成用ラムダはスカラーを返す必要があります。

mapの係数aは現在の係数ですが、`a[j]` では変換前の入力FPSのj次係数を取り出せます。名前付きのFPSなら `f[j]` も使えます。参照先が表示末尾の次の項でも、入力式を必要精度で再評価します。

Laurent級数のmapは、入力の最低次数からN-1までを変換し、それより低い次数は0のままにします。添字n/iには負の次数も入ります。例えば `map(1/(x*(1-x)),(a,n)=>n<0?0:n!*a)` なら、負の次数を消して通常のFPSにできます。負の添字の係数が常に0になるのは、負の次数を持たない通常のFPSの場合です。

```text
f = 1/(1-x)^2
map(f, (a,i) => (i+1)!*a^2)
map(f, (a,i) => i*a[i+1]^2)
map(f, i => i*f[i+1]^2)
map(f, a[n-1])
fps(n => n==0 ? 0 : 1/n)
fps(n => if(n<3, nCk(3,n), 0))
```

有限体でも次数・添字・階乗・組合せの整数引数が変わらないよう、スカラーは係数体上の値に加え、modで還元する前の厳密値を保持します。比較と `%` はその厳密値に対して行います。例えばmod2でも `fps(n=>n==0?1:0)` は定数FPSの1です。抽出した有限体の係数は `0…p-1` の代表元を整数として扱います。スカラー四則演算自体は係数体で行うので、mod上の0による除算はエラーです。

## 数式表示

入力式をASTからTeXへ変換し、KaTeXで数式プレビューします。「TeXソース」で文字列を確認し、「TeXをコピー」で入力式と結果のTeXを取得できます。入力欄は従来の式言語用であり、TeXを直接計算する入力欄ではありません。

FPSの結果は「係数表」と「級数」を切り替えられます。「級数」は `a_0+a_1x+a_2x^2+…+O(x^N)` の横向き表示です。E.G.F.では `a_n x^n/n!` として表示し、同じFPSを表します。長い式はその領域内で横スクロールできます。表示形式もブラウザに保存します。

Laurent級数は係数表・TeX・横向き表示に負の次数も含めます。「係数をコピー」では最低次数を失わないよう `{"startDegree":-1,"coefficients":["1","0",...]}` のJSONをコピーします。通常FPSの係数コピーは従来の配列形式です。

`revert(x-x^2)` の係数は `[0,1,1,2,5,14,…]`、`exp(x)` は `[1,1,1/2,1/6,…]` になります。

## 係数体・精度・表示

- **有理数 ℚ**: 分子・分母は `bigint`。浮動小数点に変換せず、約分した厳密値を表示します。
- **素数体 𝔽p**: `2 ≤ p ≤ 2147483647` の素数を指定できます。演算自体をmod上で行い、`0…p-1` の代表元を表示します。
- **精度 N**: `f+O(x^N)` としてN未満の次数を計算します。通常FPSは次数 `0…N-1` のN項、Laurent級数は負の次数も追加して表示します。設定Nは1〜64、必要な内部精度は絶対次数512までです。
- **O.G.F. / E.G.F.**: 同じFPS `f=Σ c_n x^n` に対し、通常係数 `c_n` または `a_n=n!c_n` を表示します。入力式の意味と演算は常に通常の冪級数のままです。`exp(x)` はE.G.F.表示で全て1になります。

有限体で `exp`, `log`, `integral`, `revert` を使うと、整数の逆元が必要です。標数pで割り算ができない場合はエラーにします。例えば `exp(x)` をN項計算するには `N ≤ p` が必要で、微分を含む式では追加の内部精度にも注意が必要です。小さいpでも多項式の四則演算は利用できます。E.G.F.表示は階乗が可逆な `N ≤ p` に制限します。

平方根は有理数体で有理数として存在する場合のみ計算し、先頭係数の非負の根を選びます。例えば `sqrt(2)` はエラーです。素数modではTonelli–Shanks法で根を求め、二つあるときは小さい非負代表元を先頭係数に選びます。FPSの位数が2mなら、出力N項のために入力N+m項を要求します。表示精度で全係数が0の場合は最大2N項を調べます。分母2以外の一般有理数乗は定数項1のFPSに対応します。スカラーの有理数乗は有理数として厳密に根を取れる場合（根の次数64以下）に対応し、平方根は指定係数体内の根を使います。

階乗・nCk/nPk/nHk・スターリング数は整数上で正確に計算してからmodへ写すため、例えばmod5で `nCk(10,5)=2` を計算できます。nCk/nPkは `k<0` または `k>n` で0、nHkは `k<0` で0です。

`Catalan` の係数は整数上で求めてからmodへ写すため、標数2等でも利用できます。`Catalan(f)` と `LambertW(f)` は通常FPSの合成として計算し、負の次数を持つ引数は未対応です。スカラー引数には0のみ対応し、`Catalan(0)=1`、`LambertW(0)=0` をスカラーとして返します。LambertWの係数 `(-n)^(n-1)/n!` は約分してから係数体へ写し、必要な係数の分母がmodで可逆でない場合はエラーです。fの位数に応じて、結果に寄与する次数だけを計算します。

## Laurent級数

分母の定数項が0でも、最初の非零項を探してxの因子を分離し、`K((x))` の形式Laurent級数として計算します。有理数体・素数modの両方に対応します。

```text
1/x                    # x^(-1)
x/x                    # 1
1/(x*(1-x))            # x^(-1)+1+x+x^2+...
inv(x-x^2)             # 同じ展開
(x+x^2)^-2             # x^(-2)-2*x^(-1)+3-4*x+...
(exp(x)-1)/x           # 1+x/2+x^2/6+...
coeff(1/x,-1)          # スカラーの1
```

上記の `#` 以降は説明であり、入力欄にコメントは入れないでください。

最低次数は-128までです。打ち切り次数Nは負の次数の数を含む「表示項数」ではなく、常に `O(x^N)` の絶対精度です。例えばN=6で `1/(x*(1-x))` は次数-1〜5の7個の係数を表示します。除算・乗算・整数べきでは必要な入力精度を逆算し、高次係数が低い次数へ移動しても末尾を失わないようにします。有限精度で全係数が0でも恒等的な零とは断定せず、分母・逆元の非零項を最大512まで探索します。見つからない場合は零級数または位数上限としてエラーを表示します。

Laurent級数は加減乗除・整数べき・逆元・微分・係数抽出・mapに対応します。積分はx^(-1)の係数が0の場合に対応し、有限体では各次数の分母も可逆である必要があります。負の次数が相殺されれば結果は通常FPSに戻ります。負の次数を持つ級数のE.G.F.表示・平方根・合成・合成逆関数・log/expは未対応で、明示的なエラーにします。通常FPSに戻った後は従来の演算を使えます。`compose` の第2引数の定数項0という制約も維持しています。

## 数列・漸化式・結果比較

次の関数は入力欄から使えます。係数は常に通常係数で、OGF/EGFは表示だけを切り替えます。解析レポートには係数体、候補式、条件を表示し、「値をコピー」で内容をコピーできます。有理母関数は数式表示と「復元した有理式をノートに追加」に対応します。

| 入力 | 意味 |
| --- | --- |
| `seq(0,1,1,2,3)` | 係数を列挙したFPS。列挙後は0。1〜64個のスカラー式を指定可能 |
| `linrec(2,seq(1,1),seq(0,1))` | `a_n=a_(n-1)+a_(n-2)`、初期値0,1からFPSを生成 |
| `recurrence(2,seq(0,1),(a,n)=>a[n-1]+a[n-2])` | 一般漸化式。第1引数は初期値の個数。nは現在の添字、a[j]は確定済みの過去の項 |
| `rationalGF(2,seq(1,1),seq(0,1))` | 線形漸化式から有理母関数 `x/(1-x-x^2)` を厳密に復元するレポート |
| `guess(seq(0,1,1,2,3,5,8,13),4,3)` | 最初の4項から最大3次の定係数線形漸化式を推測し、残り4項で検証 |
| `partialSums(f)` | `b_n=Σ_(k=0)^n a_k` |
| `binomialTransform(f)` | `b_n=Σ_(k=0)^n binom(n,k)a_k` |
| `inverseBinomialTransform(f)` | `b_n=Σ_(k=0)^n (-1)^(n-k)binom(n,k)a_k` |
| `hadamard(f,g)` | 係数ごとの積 `b_n=a_n c_n` |
| `even(f)` / `odd(f)` | `b_n=a_(2n)` / `b_n=a_(2n+1)` |
| `extract(f,m,r)` | `b_n=a_(mn+r)`。1≤m≤16、0≤r<m |
| `compare(f,g)` | 指定精度まで通常係数を比較し、最初に異なる次数と両係数を表示。Laurentの負次数にも対応 |

`linrec(k,c,initial)` / `rationalGF(k,c,initial)` では `c[j]` が `a_(n-1-j)` の係数です。次数kは1〜16、cとinitialには少なくともk個の係数が必要です。`recurrence` のラムダは2引数にし、履歴a自体の四則演算や未確定項・負添字の参照は拒否します。初期値にはseq以外の通常FPSも指定できます。

`guess(f,training,maxOrder)` は最小次数から学習用の方程式を厳密な体演算で解き、一意な候補だけを採用します。学習に2項以上、学習に使わない検証項を1項以上必要とし、次数上限は16です。検証項は次数の選択・係数の決定に使いません。候補なし・情報不足・検証不一致も表示します。通常FPSは表示精度N項、直接のseqやその名前参照は列挙した全項を使います。seqの末尾に0を補って検証項を増やしません。有限項での一致を数学的な恒等性の証明として扱いません。

部分和・二項変換・Hadamard積・項抽出は通常FPSを対象とし、負の項がある入力は拒否します。抽出は必要な高次係数を再評価し、例えばodd(f)のN項にはfの2N項を要求します。内部精度512を超える場合はエラーです。有限体での二項変換は整数の二項係数を体に写すため、階乗の逆元を要求しません。

### p-recursiveからの生成・微分方程式復元

`pRecursive(initial,p0,p1,…,pr)` は、n≥0で

```text
p0(n)*a_n + p1(n)*a_(n+1) + … + pr(n)*a_(n+r) = 0
```

を満たす数列を生成します。`pRecGF` は同じ引数から通常母関数 `F(x)=Σ a_n x^n` の微分方程式を復元します。係数多項式の入力中のx/Xは添字nを表します。整数・有理数・x・四則演算（除算はスカラーのみ）・非負整数べき・seqで指定し、参照先も同じ多項式構文で記述します。シフト次数rは1〜8、各多項式は8次まで、初期係数は少なくともr個指定します。

```text
pRecursive(seq(1),-1,1+x)       # a_(n+1)=a_n/(n+1): exp(x)
pRecursive(seq(1),-1-x,1)       # a_(n+1)=(n+1)*a_n: 階乗の通常母関数
pRecGF(seq(1),-1,1+x)          # F'-F=0
pRecGF(seq(1),-1-x,1)          # (1-x)F-x^2 F'=1
```

`#`以降は説明であり、入力しません。生成時に最高シフトの係数が0になる場合、先の項を一意に求められない理由と添字を表示します。微分方程式には初期値による境界項を含め、全項に共通のx因子だけを除きます。復元した作用素の最小性や特異点での解の一意性は主張しません。有限体では自明な作用素になる場合もあります。復元自体と、その方程式を現在のODEソルバーで解けることは区別してください。

## 微積分を含む再帰・連立系

通常行に `f=1+integral(f)` と入力するとexp(x)を計算できます。`f=integral(1+f^2)` のような非線形再帰にも対応します。積分は定数項0です。`f=diff(f)` のような微分再帰では「再帰の初期値」に1等を指定します。

連立欄には次のように入力できます。

```text
未知数と初期係数:
u=1
v=0

方程式:
diff(u)=-v
diff(v)=u
```

高階ODEでは `u=seq(0,1)`、`diff(diff(u))=-u` のように指定します。初期値は **通常係数** a_k（微分値u^(k)(0)をk!で割った値）です。最高微分がr階なら少なくともa_0…a_(r-1)が必要です。初期値の右辺は解く未知数に依存させません。微分と代数式を混ぜた `diff(u)=v` / `v=u^2` や、積分を介した相互再帰も扱います。

和・積・商・スカラーべき・exp/log/sqrt等の微分は連鎖律で展開します。微積分系は既存の点ごとのJacobian用Newton法から分離し、係数方向の自動微分と線形方程式で次数順に解きます。解法選択がNewtonでも微積分系は「微積分・係数逐次法」を使います。外側のdiff・項抽出等に応じて追加精度を求め、実際に確定した係数で検証できる次数だけ残差を検証します。

最高階微分を含む未確定な定数係数には線形性を要求します。例えば `(diff(u))^2=1` は `u=seq(0,1)` のように最高階の初期係数も与えると枝を指定できます。係数行列が特異になる系（例: `f=x*diff(f)`）、高い指数の微分代数系、合成・map・係数抽出を含む未知関数の循環、Laurent/Puiseux解は引き続き未対応です。特異な系を「解なし」と断定しません。微分は8階まで、内部精度512、未知数8個、既存の入力・Worker時間上限を維持します。小さい素数modで微分・積分の係数が可逆でない場合はエラーになります。

```text
    format-value.ts          型付き計算値を係数・TeX・解析レポートへ変換
  workbook.ts                行の解析・名前解決・計算結果の集約・公開API
  worker.ts                  Workerのメッセージ入口
tests/                       計算・保存・行操作・Worker管理のテスト
docs/architecture.md  設計判断と段階的な開発計画
AGENTS.md             継続作業のルール
scripts/              Node.jsのセットアップ・対応ランタイムでの起動
```

画面の変更は `ui/components/`、操作の規則は `app/`、演算の追加は `core/` と `language/` へ分けています。画面部品はコールバックで操作を通知し、計算Workerや保存先を直接操作しません。ファイル選択・ダウンロード・URLコピーだけをDocumentActionsViewのブラウザ境界に置き、JSONの検証やノートの置換・履歴はapp層に残します。組み込み関数の名前・引数数・組合せ関数の別名は `language/builtins.ts` に集約しています。

既存の `workbook.ts` からの型・上限値のインポートは引き続き利用できます。新しいUIコードは `model/` と `config/` を参照します。保存形式は従来の `version:1` を維持し、既存の式・行順・表示形式・入力幅を復元できます。

`node_modules/`, `dist/`, 一時ファイル、環境変数ファイルはGit管理対象から除外しています。`package-lock.json` は管理対象です。

設計時の参照: [Vite公式ガイド](https://vite.dev/guide/)、[TypeScriptのBigInt](https://www.typescriptlang.org/docs/handbook/2/everyday-types.html#bigint)、[形式冪級数の解説（著者公開版）](https://benjaminsambale.github.io/pdfs/fopose.pdf)、[合成逆関数の高速化（Johansson）](https://arxiv.org/abs/1108.4772)。

表示の整形は `calculation/format-value.ts`、数学的な演算は `core/`、式言語の型・評価は `language/` に分離しています。数列関数は `sequence-functions.ts` の登録表から機能別モジュールへ委譲します。補完メニューは色分け・エラー描画から独立しています。`workbook.ts` の公開入口、式の構文、version:1の保存形式、履歴の規則は維持しています。
